## 最终效果

- **博客**：`https://你的域名/` — Hugo 生成的静态站点，支持亮/暗主题、全文搜索、按时间归档
- **评论**：每篇文章底部有评论区，无需登录即可匿名评论 + 点赞
- **部署**：`git push` 后约 30 秒自动上线，无需手动操作服务器

**技术栈总览：**

| 层级 | 技术 | 用途 |
|------|------|------|
| 静态生成 | Hugo Extended | 将 Markdown 编译为 HTML/CSS/JS |
| 主题 | PaperMod | 响应式布局、暗色模式、搜索、归档 |
| 托管 | Cloudflare Pages | 免费静态托管，全球 CDN，自动部署 |
| 评论 | Twikoo | 评论+点赞，数据存 Cloudflare D1 |
| 域名 | 你的域名 | 自定义域名，支持 HTTPS |

## 1. 前置条件

开始之前，请确保你准备好以下内容：

### 1.1 软件安装

| 软件 | 用途 | 安装方式 |
|------|------|----------|
| **Hugo Extended** | 静态站点生成器 | [官方安装指南](https://gohugo.io/installation/)，务必选择 **Extended** 版本（PaperMod 需要 SCSS 编译） |
| **Git** | 版本控制，连接 GitHub | `winget install Git.Git` 或 [git-scm.com](https://git-scm.com/) |
| **Node.js (可选)** | 部署 Twikoo 后端时用到 | `winget install OpenJS.NodeJS` 或 [nodejs.org](https://nodejs.org/)，建议 LTS 版本 |

安装完成后验证：

```bash
hugo version
# 输出应包含 "extended"，例如：hugo v0.163.1+extended ...

git --version
# git version 2.x.x

node --version  # 可选
# v20.x.x
```

### 1.2 注册账号

| 平台 | 用途 | 注册地址 |
|------|------|----------|
| **GitHub** | 存放博客源码 | [github.com](https://github.com) |
| **Cloudflare** | 托管网站 + 部署评论后端 | [cloudflare.com](https://cloudflare.com) |

### 1.3 域名（可选但推荐）

- 任何域名注册商均可（Cloudflare Registrar、Namecheap、阿里云等）
- 将域名的 DNS 服务器托管到 Cloudflare（参见 [第 8 节](#8-绑定自定义域名)）
- 如果暂时没有域名，Cloudflare Pages 会提供一个免费的 `*.pages.dev` 子域名，但 `workers.dev` 子域名在大陆可能不可用（影响评论功能）

## 2. 本地搭建 Hugo

### 2.1 创建站点

打开终端（Windows 推荐用 Git Bash 或 PowerShell），执行：

```bash
# 在你想要存放项目的目录下
hugo new site myblog
cd myblog
```

执行后会生成以下目录结构：

```
myblog/
├── archetypes/    # 文章模板
├── assets/        # SCSS、JS 等需要编译的资源
├── content/       # 所有文章（Markdown）存放处
├── data/          # 数据文件（可选）
├── layouts/       # 自定义模板（覆盖主题默认模板）
├── public/        # 构建输出（hugo 命令生成，不需手动编辑）
├── static/        # 静态文件（图片、字体等，直接复制到 public）
├── hugo.yaml      # 站点配置文件（旧版叫 config.toml）
└── .gitignore     # Git 忽略规则
```

### 2.2 安装 PaperMod 主题

> **重要**：不要用 `git submodule add`。Cloudflare Pages 构建时不会拉取 submodule，会导致主题文件缺失、样式错乱。

```bash
# 直接 clone 主题到 themes 目录
git clone https://github.com/adityatelange/hugo-PaperMod.git themes/PaperMod

# 删除 .git 目录，使主题文件作为普通文件纳入仓库
# Windows PowerShell:
Remove-Item -Recurse -Force themes/PaperMod/.git
# Git Bash / Linux / macOS:
rm -rf themes/PaperMod/.git
```

### 2.3 初始化 Git 仓库

```bash
git init
git add .
git commit -m "初始化 Hugo + PaperMod"
```

## 3. 配置 PaperMod 主题

编辑项目根目录下的 `hugo.yaml`（如果没有就新建）：

```yaml
# ===== 基础设置 =====
baseURL: https://你的域名/          # 生产环境地址，本地开发用 http://localhost:1313/
languageCode: zh-cn                 # 语言代码
title: 你的博客名称
theme: PaperMod                     # 指定主题

# ===== 文章链接格式 =====
# 使用 /posts/文章文件名/ 作为 URL
permalinks:
  posts: /posts/:filename/

# ===== Markdown 渲染 =====
markup:
  goldmark:
    renderer:
      unsafe: true                 # ⚠️ 必须开启！允许 Markdown 中嵌入 HTML（评论框靠这个注入）

# ===== 菜单导航 =====
menu:
  main:
    - identifier: archives
      name: 归档
      url: /archives/
      weight: 10
    - identifier: search
      name: 搜索
      url: /search/
      weight: 20
    - identifier: tags
      name: 标签
      url: /tags/
      weight: 30

# ===== PaperMod 参数 =====
params:
  # 作者和描述
  author: 你的名字
  description: 记录奇思妙想，分享有趣的东西

  # 主题外观
  defaultTheme: auto                # auto / light / dark
  ShowReadingTime: true             # 显示阅读时间
  ShowShareButtons: false           # 如果你用了自定义分享按钮，这里关掉
  ShowPostNavLinks: true            # 文章底部上下篇导航
  ShowBreadCrumbs: true             # 面包屑导航
  ShowCodeCopyButtons: true         # 代码块复制按钮
  ShowToc: true                     # 显示目录
  TocOpen: true                     # 目录默认展开

  # 首页
  homeInfoParams:
    Title: 欢迎 👋
    Content: 记录学习、思考和有趣的事。

  # 页脚
  footer:
    text: "© 2025 你的名字 · [GitHub](https://github.com/你的用户名/你的仓库)"

  # 社交媒体图标（PaperMod 内置，可选）
  socialIcons:
    - name: github
      url: https://github.com/你的用户名

  # 搜索引擎
  fuseOpts:
    isCaseSensitive: false
    shouldSort: true
    location: 0
    distance: 1000
    threshold: 0.4
    minMatchCharLength: 0
    keys:
      - title
      - content
      - summary
```

### 配置要点说明

| 配置项 | 说明 |
|--------|------|
| `markup.goldmark.renderer.unsafe: true` | **必须开启**，否则 Markdown 文章中插入的 HTML 代码（如评论组件）会被滤掉 |
| `defaultTheme: auto` | 跟随系统主题，读者手动切换后优先使用手动选择 |
| `ShowShareButtons: false` | 如果你自己写了分享组件（见第 5 节），关掉 PaperMod 内置的 |

## 5. 自定义评论、点赞、分享

PaperMod 原生不内置评论系统。我们需要在主题模板的基础上，在文章底部注入 Twikoo 评论框、点赞按钮、分享按钮。

### 5.1 创建自定义模板

```bash
mkdir -p layouts/partials
```

创建 `layouts/partials/comments.html`，写入以下内容：

```html
<!--
  Twikoo 评论 + 匿名点赞 + 分享按钮
  搜索 🔧 可快速定位所有需要修改的地方
-->

<hr style="margin-top: 2rem;" />

<!-- ===== 点赞区域 ===== -->
<div style="display: flex; align-items: center; gap: 12px; margin: 1rem 0; flex-wrap: wrap;">
  <button id="like-btn" onclick="toggleLike()"
    style="border: none; background: none; cursor: pointer; font-size: 1.2em; display: flex; align-items: center; gap: 4px;">
    ❤️ <span id="like-count">0</span>
  </button>

  <!-- ===== 🔧 分享按钮 ===== -->
  <button onclick="sharePost()"
    style="border: none; background: none; cursor: pointer; font-size: 1.2em;">
    📤
  </button>
</div>

<!-- ===== 🔧 评论区域 ===== -->
<div id="twikoo"></div>

<!-- Twikoo JS SDK -->
<script src="https://cdn.jsdelivr.net/npm/twikoo@latest/dist/twikoo.all.min.js"></script>

<script>
// ===== Twikoo 评论初始化 =====
// 🔧 替换为你的 Twikoo 后端地址（见第 9 节部署后获得）
twikoo.init({
  envId: 'https://你的-twikoo-域名/',
  el: '#twikoo',
  // 仅需昵称即可评论
  region: '',
  lang: 'zh-CN',
});

// ===== 匿名点赞（localStorage 持久化，每人每文章一次） =====
(function() {
  var slug = window.location.pathname.replace(/\/$/, '') || 'home';
  var key = 'like_' + slug;
  var countKey = 'likeCount_' + slug;
  var liked = localStorage.getItem(key) === '1';
  var count = parseInt(localStorage.getItem(countKey) || '0', 10);

  var btn = document.getElementById('like-btn');
  var cnt = document.getElementById('like-count');

  function render() {
    cnt.textContent = count;
    btn.style.opacity = liked ? '0.5' : '1';
  }

  window.toggleLike = function() {
    if (liked) {
      liked = false;
      count = Math.max(0, count - 1);
      localStorage.setItem(key, '0');
    } else {
      liked = true;
      count += 1;
      localStorage.setItem(key, '1');
    }
    localStorage.setItem(countKey, '' + count);
    render();
  };

  render();
})();

// ===== 🔧 分享功能（Web Share API + 复制链接兜底） =====
function sharePost() {
  var url = window.location.href;
  var title = document.title;

  if (navigator.share) {
    navigator.share({ title: title, url: url }).catch(function(){});
  } else {
    navigator.clipboard.writeText(url).then(function() {
      alert('链接已复制到剪贴板');
    }).catch(function() {
      prompt('复制以下链接分享：', url);
    });
  }
}
</script>
```

### 5.2 注册模板片段

PaperMod 提供了 `extend_footer` 和 `comments` 两个插槽。我们需要确保主题的 `single.html` 模板会调用它（PaperMod 默认在文章页底部调用了 `partial "comments.html"`，无需额外操作）。

如果发现评论框没出现，检查 `themes/PaperMod/layouts/_default/single.html` 中是否有：

```html
{{- partial "comments.html" . -}}
```

### 5.3 配置要点

- 所有标记了 `🔧` 的地方都是你可以修改的文案和地址
- `envId` 的值在部署 Twikoo 后端后获得（见第 9 节）
- 点赞数据只存在用户的浏览器本地（`localStorage`），不同设备/浏览器之间不同步
- 分享按钮优先使用系统原生分享（手机），桌面端自动降级为复制链接

## 6. 推送到 GitHub

### 6.1 在 GitHub 创建仓库

1. 登录 GitHub → 右上角 `+` → **New repository**
2. 仓库名随意（如 `myblog`），可见性建议选 **Public**（Cloudflare Pages 免费额度对公开仓库更宽松）
3. 不要勾选 "Add a README file"（本地已经有了）
4. 创建后记下仓库地址，两种协议二选一：
   - SSH：`git@github.com:你的用户名/你的仓库.git` ✅ 推荐（大陆不受干扰）
   - HTTPS：`https://github.com/你的用户名/你的仓库.git`

### 6.2 配置 SSH 密钥（推荐）

如果选择 SSH 协议，先配置密钥：

```bash
# 生成 SSH 密钥（如果还没有）
ssh-keygen -t ed25519 -C "your-email@example.com"
# 一路回车即可

# 复制公钥
cat ~/.ssh/id_ed25519.pub
# 或在 Windows PowerShell 中：
# Get-Content ~/.ssh/id_ed25519.pub | Set-Clipboard
```

然后去 GitHub → Settings → **SSH and GPG keys** → **New SSH key**，粘贴公钥，保存。

> **为什么推荐 SSH**：大陆地区 GitHub HTTPS 推送经常超时或被干扰，SSH 不受影响。

### 6.3 关联远程仓库并推送

```bash
# 添加远程仓库（用 SSH 地址）
git remote add origin git@github.com:你的用户名/你的仓库.git

# 拉取远程分支（如果仓库不为空）
git pull origin main --allow-unrelated-histories

# 推送
git push -u origin main
```

### 6.4 .gitignore 建议

确保 `.gitignore` 中包含：

```
public/          # Hugo 构建输出，不需要提交
resources/       # Hugo 缓存
.hugo_build.lock
```

## 7. 连接 Cloudflare Pages 自动部署

### 7.1 创建 Pages 项目

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)
2. 左侧菜单 → **Workers & Pages** → **Pages** 标签页 → **连接到 Git**
3. 授权 GitHub，选择你的博客仓库
4. 点击 **开始设置**

### 7.2 构建配置

在设置表单中填入：

| 字段 | 值 | 说明 |
|------|------|------|
| **框架预设** | `Hugo` | 自动设置构建命令和输出目录 |
| **构建命令** | `hugo` | Hugo 的默认构建命令 |
| **输出目录** | `public` | Hugo 构建产物的目录 |
| **环境变量（高级）** | 点击展开 | 见下方 |

添加环境变量：

| 变量名 | 值 | 说明 |
|--------|------|------|
| `HUGO_VERSION` | `0.163.1` | **必须设置！** 指定 Hugo 版本，否则 Cloudflare 可能用旧版构建失败 |

> **为什么必须设 `HUGO_VERSION`**：Cloudflare Pages 默认的 Hugo 版本可能很老，PaperMod 需要较新的 Hugo 版本才能正确编译 SCSS。版本号填你本地 `hugo version` 输出的版本号。

### 7.3 首次部署

点击 **保存并部署**。Cloudflare 会：

1. 克隆你的仓库
2. 安装指定版本的 Hugo
3. 执行 `hugo` 构建
4. 将 `public/` 目录部署到全球 CDN

首次构建大约需要 1-2 分钟。成功后你会看到一个 `*.pages.dev` 的临时域名。

### 7.4 设置自动部署

默认就是自动的：每次 `git push` 到 `main` 分支，Cloudflare Pages 会自动重新构建和部署。在项目的 **设置 → 构建和部署** 中可以查看构建设置和部署历史。

## 8. 绑定自定义域名

### 8.1 前提

将你的域名的 DNS 服务器托管到 Cloudflare（免费）：

1. 域名注册商处将 DNS 服务器改为 Cloudflare 提供的两个地址（在添加站点时 Cloudflare 会告诉你）
2. 等待 DNS 变更生效（几分钟到 48 小时不等）

### 8.2 添加自定义域

1. Cloudflare Pages 项目 → **自定义域** → **设置自定义域**
2. 输入你的域名（如 `blog.你的域名.com`）
3. Cloudflare 会自动添加 DNS CNAME 记录，指向 Pages 项目的 `*.pages.dev` 地址
4. 等待 SSL 证书自动签发（通常 2-5 分钟）

### 8.3 更新 hugo.yaml

部署成功后，更新 `baseURL` 为你的自定义域名：

```yaml
baseURL: https://blog.你的域名.com/
```

然后提交并推送，触发重新部署。

## 9. 部署 Twikoo 评论后端

Twikoo 是一个开源的评论系统，后端跑在 Cloudflare Workers 上，数据存在 D1 数据库中。完全免费。

### 9.1 获取 Twikoo 源码

```bash
# 在 myblog 项目之外的目录
git clone https://github.com/bluerosion/twikoo-cloudflare.git twikoo-cf
cd twikoo-cf
npm install
```

### 9.2 创建 D1 数据库

1. Cloudflare Dashboard → **Workers & Pages** → **D1** → **创建数据库**
2. 数据库名称随意（如 `twikoo`）
3. 创建后记下 **数据库 ID**（一串 UUID）

### 9.3 配置 wrangler.toml

编辑 `twikoo-cf/wrangler.toml`：

```toml
name = "twikoo"
main = "src/index.js"
compatibility_date = "2024-01-01"

[[d1_databases]]
binding = "DB"                       # 代码中用 DB 引用数据库
database_name = "twikoo"             # 你创建的 D1 数据库名称
database_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"  # 替换为你的数据库 ID
```

### 9.4 初始化数据库

```bash
# 创建 Twikoo 需要的表结构
npx wrangler d1 execute twikoo --file=./schema.sql
```

如果 `schema.sql` 不存在，手动执行：

```bash
npx wrangler d1 execute twikoo --command="CREATE TABLE IF NOT EXISTS twikoo_comment (id INTEGER PRIMARY KEY AUTOINCREMENT, url TEXT, nick TEXT, mail TEXT, link TEXT, ua TEXT, ip TEXT, master INTEGER, comment TEXT, commentText TEXT, rid INTEGER, uaText TEXT, created INTEGER, updated INTEGER, isSpam INTEGER, hidden INTEGER, pid TEXT, rpid TEXT, avatar TEXT, commentMeta TEXT, rua TEXT, ipRegion TEXT, isVerify INTEGER, favatar TEXT, from TEXT)"
```

### 9.5 部署 Worker

```bash
npx wrangler deploy
```

部署成功后你会获得一个 `twikoo.你的用户名.workers.dev` 地址。

### 9.6 为 Worker 绑定自定义域名

> **关键步骤**：`workers.dev` 域名在大陆可能无法访问，必须绑定自己的域名。

1. Cloudflare Dashboard → **Workers & Pages** → 你的 `twikoo` worker
2. **触发器** 标签页 → **自定义域** → **添加自定义域**
3. 输入一个子域名，如 `twikoo.你的域名.com`
4. Cloudflare 会自动添加 DNS 记录并签发 SSL 证书

### 9.7 关联到博客

回到 `myblog` 项目的 `layouts/partials/comments.html`，将 `envId` 改为你的 Worker 自定义域名：

```javascript
twikoo.init({
  envId: 'https://twikoo.你的域名.com/',   // ← 这里
  el: '#twikoo',
});
```

提交并推送，评论功能就上线了。

### 9.8 管理评论

1. 打开任意一篇有评论区文章
2. 评论区右下角有一个齿轮图标 ⚙️（仅博主可见，需要登录）
3. 首次登录：在评论区输入框输入密码（密码在 `wrangler.toml` 或环境变量中设置，默认无密码）
4. 登录后可以删除、隐藏、置顶评论

Twikoo 管理面板的配置（可选，在 Worker 环境变量中设置）：

| 变量 | 值 | 说明 |
|------|------|------|
| `DISPLAYED_FIELDS` | `nick` | 评论区显示哪些字段 |
| `REQUIRED_FIELDS` | `nick` | 哪些字段必填 |
| `ADMIN_PASS` | `你的密码` | 管理员密码 |

## 10. 大陆访问优化

### 10.1 关闭 Cloudflare 代理

Cloudflare 默认开启代理（橙色云朵），但代理 IP 在大陆访问体验不稳定。如果目标读者主要在大陆：

1. Cloudflare Dashboard → 你的域名 → **DNS** → **记录**
2. 找到博客和 Twikoo 的 DNS 记录
3. 点击橙色云朵图标，切换为灰色（**仅 DNS**）

这样 Cloudflare 只做 DNS 解析，不做流量代理。

### 10.2 优选 CNAME（进阶）

直接 CNAME 到 `*.pages.dev` 在大陆可能速度不理想。社区有维护 Cloudflare 优选 IP 的方案：

1. 将 DNS CNAME 记录指向优选节点（如 `cf-cname.xingpingcn.top` 等社区维护地址）
2. 这些节点会自动转发到最优的 Cloudflare IP

> 优选节点列表会随 GFW 策略变化，搜索 "Cloudflare 优选 CNAME" 获取最新方案。

### 10.3 总结：最终 DNS 记录

| 类型 | 名称 | 目标 | 代理 |
|------|------|------|------|
| CNAME | `blog` | 优选 CNAME 节点 | 关闭（灰色） |
| CNAME | `twikoo` | Cloudflare Pages 或 Worker 地址 | 关闭（灰色） |

## 11. 日常写作与维护

### 11.1 写新文章

```bash
cd myblog

# 创建新文章
hugo new posts/我的新文章.md
# 文件生成在 content/posts/我的新文章.md

# 用你喜欢的编辑器编辑
# 文章开头会自动生成 front matter：
# ---
# title: "我的新文章"
# date: 2025-06-13
# draft: true
# ---
```

### 11.2 发布文章

```bash
# 将 draft: true 改为 draft: false，或者删掉 draft 这一行
git add content/posts/我的新文章.md
git commit -m "新文章：我的新文章"
git push
```

推送后 Cloudflare Pages 自动构建，大约 30 秒后上线。

### 11.3 本地预览

```bash
hugo server -D
# -D 参数包含草稿文章
# 浏览器打开 http://localhost:1313
```

### 11.4 修改配置或模板

- 改站点配置 → 编辑 `hugo.yaml`
- 改评论/点赞/分享 → 编辑 `layouts/partials/comments.html`，搜索 `🔧` 定位所有可改的文案
- 改样式 → 在 `assets/css/extended/` 下新建 `.css` 文件，PaperMod 会自动加载
- 改完 `git push` 即可生效，无需任何手动部署

### 11.5 Twikoo 评论数据备份

D1 数据库目前没有自动备份，建议定期手动导出：

```bash
cd twikoo-cf
npx wrangler d1 export twikoo --output=backup.sql
```

## 12. 常见问题排查

### 12.1 构建部署

| 问题 | 原因 | 解决 |
|------|------|------|
| 构建失败：`Error: Error building site: SCSS processing failed` | Hugo 版本不是 Extended，或版本太老 | 在 Cloudflare Pages 环境变量中设置 `HUGO_VERSION` 为本地版本号 |
| PaperMod 样式完全不显示 | 主题通过 git submodule 添加，Cloudflare Pages 不拉取 submodule | 删除 `themes/PaperMod/.git`，将主题作为普通文件提交 |
| 归档/搜索/标签页面 404 | 缺少对应的 `_index.md` 文件 | 确保 `content/archives/_index.md`、`content/search/_index.md`、`content/tags/_index.md` 存在 |
| 首页显示空白 | `hugo.yaml` 中忘记设置 `theme: PaperMod` | 检查配置文件是否有 `theme: PaperMod` |

### 12.2 评论系统

| 问题 | 原因 | 解决 |
|------|------|------|
| 评论框不出现 | `markup.goldmark.renderer.unsafe` 未开启 | 设为 `true`，Markdown 中的 HTML 才会被渲染 |
| 评论提交失败 | 使用了 `workers.dev` 域名（被墙） | 给 Twikoo Worker 绑定自定义域名 |
| Worker 部署失败、语法错误 | PowerShell `echo` 等命令在写文件时引入 UTF-16 BOM | 用 Git Bash 的 `printf` 写入文件，或直接在 Cloudflare Dashboard 中编辑 |
| 评论加载中一直转圈 | `envId` 地址写错，或 Worker 未部署成功 | 在浏览器打开 `https://你的-twikoo-域名/`，应看到 Twikoo 版本信息 |

### 12.3 Git 和网络

| 问题 | 原因 | 解决 |
|------|------|------|
| `git push` 超时 | 大陆 GitHub HTTPS 被干扰 | 改用 SSH 协议：`git remote set-url origin git@github.com:用户名/仓库.git` |
| `git push` 报 Permission denied | SSH 公钥未添加到 GitHub | GitHub → Settings → SSH Keys，添加 `~/.ssh/id_ed25519.pub` |
| 网站国内访问慢 | Cloudflare 代理 IP 被干扰 | 关闭代理（橙色云朵 → 灰色），仅用 DNS 解析 |

### 12.4 JavaScript 错误

| 问题 | 原因 | 解决 |
|------|------|------|
| 控制台报 `Uncaught SyntaxError` | Hugo 模板中 `safeJS` 输出的字符串缺引号 | 对 URL 等字符串使用 `| jsonify` 过滤器，确保输出带引号 |
| 分享按钮不工作 | HTTP 环境下 `navigator.share()` 不可用 | 确保网站通过 HTTPS 访问（Cloudflare Pages 默认开启） |
